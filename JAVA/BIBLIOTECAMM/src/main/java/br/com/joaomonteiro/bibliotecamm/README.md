# 📚 Sistema de Biblioteca em Java

Sistema de gerenciamento de biblioteca desenvolvido em Java com foco em Programação Orientada a Objetos (POO), arquitetura em camadas e aplicação de regras de negócio.

O projeto permite o cadastro de usuários, livros, DVDs e revistas, além de realizar empréstimos, devoluções, controle de disponibilidade, atraso, multas e bloqueio automático de usuários.

Durante o desenvolvimento foram aplicados conceitos importantes de engenharia de software e Java, como encapsulamento, herança, polimorfismo, abstração, separação de responsabilidades (`model`, `repository` e `service`), tratamento de exceções e uso de `enum` com comportamento próprio para controle de status dos empréstimos.

Também foram utilizadas coleções do Java (`List`, `LinkedList`) para armazenamento em memória e a API moderna de datas (`LocalDate` e `ChronoUnit`) para controle de prazos e cálculo de multas.

O sistema foi estruturado pensando em escalabilidade e evolução futura, permitindo posteriormente a implementação de persistência em banco de dados, interface gráfica, API REST com Spring Boot, autenticação de usuários e testes automatizados.

Projeto desenvolvido com objetivo de praticar lógica de programação, orientação a objetos e organização de código utilizando Java.
